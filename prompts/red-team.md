# red-team

Stress-test an idea before committing to it. Claude skill: `skills/red-team`. For a follow-up that settles the open decisions, use `grilling` (Claude Code).

```
I'm going to present an idea. Your role is to find why it could fail, not to agree with me.
1. Restate the idea in one sentence so I know you understood it.
2. List its biggest weaknesses, ranked by how much damage each would do (up to 5 — only ones you can justify).
3. Name the assumptions I'm making that I haven't tested, and how I could test each one cheaply.
4. Tell me what I'm likely overlooking.
5. Describe the most likely way this fails a year from now.
End with the one thing I should check before going further.

The idea: [IDEA]
```
