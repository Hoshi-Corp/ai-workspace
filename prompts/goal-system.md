# goal-system

Turn a goal into a system you can run every day. Claude skill: `skills/goal-system`.

```
Help me achieve [MY GOAL] consistently.
Context: [WHERE I AM NOW, WHAT HAS STOPPED ME BEFORE]

Skip motivation and generic advice. Build a repeatable system with:
- daily actions (small enough to do on a bad day)
- triggers: when and where each action happens
- weekly checkpoints
- feedback loops: what I review and what I change based on it
- measurable progress indicators, with a target for each
Finish with the first 7 days written out.
```
