# learning-plan

Plan how to master a skill. Claude's `learn` skill covers learning paths and study materials; use this when you want a full multi-week system.

```
I want to master [SKILL] as efficiently as possible.
My current level: [LEVEL]   Time available: [HOURS PER WEEK]   Goal: [WHAT I WANT TO BE ABLE TO DO]

Build a learning system that uses deliberate practice, active recall, spaced repetition, and hands-on projects:
1. The 20% of knowledge that gives 80% of the practical benefit, in the order to learn it.
2. A week-by-week plan with specific practice sessions and a hands-on project per phase.
3. A recall and review schedule (what to review, when).
4. How I'll know I've reached each milestone — a concrete test, not a feeling.
```
