# deployments

What's actually deployed and running right now, organized by platform. This is the "state of the world" catalog — separate from `workflows/`, `skills/`, and `agents/`, which hold the reusable definitions themselves.

- `claude/` — Claude scheduled tasks, projects, and plugins
- `chatgpt/` — ChatGPT scheduled tasks and custom GPTs
- `codex/` — Codex automations

Keep each platform's file current when tasks are added, changed, or removed — this is meant to be a trustworthy inventory, not a one-time snapshot.
