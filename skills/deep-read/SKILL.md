---
name: deep-read
description: Deep read of an article, book, transcript, or document, extracting insight beyond a summary. Use when the user shares reading material and wants its key ideas, hidden assumptions, or what they can apply.
---

Go past summary: the user wants what's valuable, hidden, and usable.

1. Extract, ranked within each section:
   - **Most valuable ideas**
   - **Implicit hypotheses** — what the source assumes without stating
   - **Counterintuitive insights** — where it contradicts the usual view
   - **Practical applications**
   - **Apply this week** — concrete actions for the user
2. **Weak spots**: where the source is wrong, overstated, or thinly supported.
3. Anchor every point to the passage it comes from (quote or locate it).

Done when every point traces to a passage and the "apply this week" items are actions, not themes.
