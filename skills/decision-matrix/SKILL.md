---
name: decision-matrix
description: Decision matrix comparing options the user is choosing between. Use when the user is undecided between two or more options, or asks which one to pick.
---

1. Establish the options and the user's priorities with a weight for each. If priorities or weights are missing, ask for them in one message and wait — invented priorities make the matrix meaningless.
2. Build a table: rows are the weighted priorities plus **risks**, **opportunity cost**, and **long-term consequences**; columns are the options. Score each cell 1–5 with a one-line reason. Show the weighted totals.
3. Recommend the option most likely to give the best outcome and state your confidence.
4. Name the **flip condition**: what would have to be true for the other option to win, and how the user could check it.

Done when every score has a reason and the recommendation follows from the weighted totals (or you explain why it overrides them).
