---
name: goal-system
description: Turn a goal into a repeatable system of daily actions, triggers, and tracking. Use when the user wants to achieve a goal consistently, build a habit, or stop falling off a routine.
---

Build a system, not a pep talk.

1. Establish the goal, where the user is now, and what has made them stop before. Ask in one message only for what's missing.
2. Design the system:
   - **Daily actions** — small enough to do on a bad day.
   - **Triggers** — the when and where of each action, anchored to something already in their day.
   - **Weekly checkpoint** — what to review and the questions to answer.
   - **Feedback loop** — which result changes which part of the system.
   - **Progress indicators** — measurable, each with a target.
3. Address each past failure the user named with a specific part of the system.
4. Write out the first 7 days.

Done when every indicator is a number the user can record and every action has a trigger.
