# Restaurant Curator

**Purpose:** Produce a selective weekly guide to memorable, culturally distinctive meals, primarily in Ottawa and secondarily along the Toronto–Montreal corridor.

**Schedule:** Once a week, every Thursday. The source conversation does not specify a time of day or timezone.

**Inputs:** The [reusable prompt](prompt.md) and current restaurant, menu, opening, and event information.

**Expected output:** A short, selective report explaining why each recommendation is worthwhile and what specifically to order or experience, with sources supporting current operating, opening, or event details. Favor regional depth and cultural distinctiveness over novelty or list length.

**Deployment:** See the [ChatGPT scheduled-task catalog](../../deployments/chatgpt/scheduled-tasks.md#restaurant-curator). This definition preserves the user's existing task; storing it here does not create or change a live schedule.
